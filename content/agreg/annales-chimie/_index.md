### Epreuve A : Composition de chimie
- Format : 5h, une soixantaine de questions. Niveau prépa PC, environ CCINP. Quelques questions de pédagogie.
- Pour réussir : Faire un maximum de questions en faisant très attention à la rédaction.

### Epreuve B : Composition de physique
- Format : 5h, une soixantaines de questions. Physique niveau prépa. Très complet sur le programme !
- Pour réussir : aller chercher les points sur les chapitres de physique que vous maîtrisez.

### Epreuve C : Problème de chimie
- Format : 6h, 80 questions, il y a deux types de sujet :
  - Soit une notion très exotique : la difficulté vient de comprendre ce qui se passe; cependant les questions sont "relativement" simples.
  - Soit basé sur le programme de L3 mais en très dur.
